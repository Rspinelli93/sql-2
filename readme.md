# SQL · Relationships and joins

A SQL exercise file exploring relational table design and joins with users, roles, categories, and related data. The statements use MySQL-style syntax such as AUTO_INCREMENT.

**Collection:** Scraping and data · [Project directory](https://github.com/Rspinelli93/Rspinelli93/blob/main/PROJECTS.md)

## Use the notebook

Open the SQL source in your database editor and work through one exercise at a time with the corresponding dataset.

## Implementation notes

Run selected sections in a disposable MySQL-compatible database. The file contains schema-changing statements and is a sequence of exercises rather than an idempotent migration.
